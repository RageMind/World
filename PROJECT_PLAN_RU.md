# YourWill — Living World Sandbox

## Краткое описание

**YourWill** — это уютная 2D/isometric sandbox-игра про маленький живой остров. Игрок не управляет жителями напрямую, а влияет на мир: создаёт природу, размещает костры, позже строит дома, меняет окружение и наблюдает, как жители сами живут, собирают ресурсы, строят и развиваются.

Главная идея: **маленький живой мир, который развивается сам, но игрок может мягко вмешиваться**.

Визуальная база проекта сейчас фиксируется как рабочая:

- isometric/2.5D вид;
- Kenney terrain assets для земли/воды/берегов;
- 2 стартовых жителя;
- стартовый костёр;
- анимация ходьбы жителей;
- карта с островом, лесом по краям и чистой центральной зоной.

## Жёсткие правила разработки

1. Рабочая ветка проекта: `cozy-current`.
2. Новые ветки больше не создавать без отдельной команды владельца проекта.
3. Не переписывать весь `main.js` целиком без необходимости.
4. Визуал terrain не откатывать на старые версии.
5. Новые текстуры не рисовать вручную, если нужны ассеты — брать готовые ассеты из разрешённых/свободных паков, в первую очередь Kenney.
6. Каждая доработка должна быть маленькой и проверяемой.
7. После каждого этапа проект должен открываться на VPS без пустого экрана.

- Isometric карта.

### Главная проблема сейчас

Проект уже имеет рабочий визуальный прототип, но sandbox-системы нужно добавлять аккуратно, маленькими патчами, чтобы не сломать рендер и не потерять визуальный стиль.

## Цель ближайшего этапа

Сделать из визуального прототипа **первую настоящую игровую sandbox-версию**, где игрок может влиять на мир, а жители реагируют на изменения.

## Roadmap

### Этап 1 — стабилизация текущей версии

Цель: закрепить рабочую основу.

Задачи:

- Проверить, что `cozy-current` открывается на VPS.
- Убедиться, что карта, жители, костёр и анимация работают.
- Убрать или не использовать сломанные ветки/версии.
- Зафиксировать текущую рабочую сборку как baseline.

Критерий готовности:

- При открытии страницы видна карта, 2 жителя и костёр.
- Жители двигаются.
- Нет пустого экрана.

### Этап 2 — выбор объектов через Hand

Цель: игрок может нажимать на жителя/дерево/камень/костёр и видеть информацию.

Задачи:

- Добавить hit-test по объектам.
- При инструменте Hand показывать выбранный объект.
- Выводить короткое описание:
  - житель: имя, состояние, цель;
  - дерево: ресурс wood;
  - камень: ресурс stone;
  - костёр: стартовая зона.

Критерий готовности:

- Нажатие по объекту показывает понятную информацию.

### Этап 3 — Nature: посадка дерева

Цель: инструмент Nature должен реально менять мир.

Задачи:

- При выборе Nature и тапе по земле ставить дерево.
- Запретить установку дерева на воду.
- Добавить маленький визуальный эффект появления.
- После посадки дерево становится объектом, который жители смогут использовать позже.

Критерий готовности:

- Игрок нажимает Nature → тапает по земле → появляется дерево.

### Этап 4 — ресурсы

Цель: добавить базовую экономику.

Ресурсы:

- Wood — дерево.
- Stone — камень.
- Food — еда/ягоды.

Задачи:

- Добавить счётчики ресурсов в UI.
- Привязать деревья к wood.
- Камни к stone.
- Кусты/ягоды к food.

Критерий готовности:

- В UI видно количество ресурсов.

### Этап 5 — поведение жителей: сбор ресурсов

Цель: жители сами начинают работать.

Задачи:

- Житель ищет ближайшее дерево/камень/куст.
- Идёт к нему.
- Делает простую working-анимацию.
- После завершения добавляет ресурс в общий склад.
- Объект исчезает или уменьшается после сбора.

Критерий готовности:

- Жители сами собирают wood/stone/food.

### Этап 6 — Home: чертёж дома

Цель: игрок может поставить место будущего дома.

Задачи:

- Инструмент Home ставит blueprint на землю.
- Нельзя ставить на воду.
- Blueprint требует ресурсы.
- Жители видят blueprint как задачу.

Критерий готовности:

- Игрок ставит чертёж дома.
- Он отображается на карте.

### Этап 7 — строительство дома

Цель: жители строят дом из ресурсов.

Задачи:

- Если хватает wood/stone, житель идёт к blueprint.
- Проигрывается working-анимация.
- Ресурсы списываются.
- Blueprint превращается в дом.

Критерий готовности:

- Жители строят первый дом.

### Этап 8 — день/ночь

Цель: мир получает цикл жизни.

Задачи:

- Добавить время суток.
- Днём жители работают.
- Вечером возвращаются к костру/дому.
- Ночью отдыхают.
- Визуально затемнять сцену ночью.

Критерий готовности:

- Поведение жителей меняется в зависимости от времени.

### Этап 9 — сохранение мира

Цель: прогресс не пропадает после перезагрузки.

Задачи:

- Сохранять карту, объекты, жителей, ресурсы в `localStorage`.
- Добавить кнопку/режим сброса мира позже.

Критерий готовности:

- После обновления страницы мир остаётся прежним.

### Этап 10 — расширение sandbox

Идеи для следующих версий:

- Рождение новых жителей.
- Голод/сон/настроение.
- Улучшение домов.
- Поля/фермы.
- Дрова/еда/камень как реальные переносимые предметы.
- События: дождь, пожар, ночь, болезнь.
- Больше инструментов игрока.
- Животные.
- Маленькие истории жителей.

## Минимальная playable-цель

Первая полноценная playable-версия должна содержать:

1. Остров.
2. 2 жителей.
3. Костёр.
4. Посадку деревьев.
5. Сбор дерева/камня/еды.
6. Чертёж дома.
7. Постройку дома.
8. День/ночь.
9. Сохранение.

После этого проект уже можно считать настоящим ранним sandbox-прототипом.

## Правило следующей разработки

Каждая новая система добавляется только маленьким шагом:

1. Сделать одну функцию.
2. Запушить в `cozy-current`.
3. Проверить на VPS.
4. Только потом идти дальше.

Нельзя снова переписывать весь проект одним большим куском.
